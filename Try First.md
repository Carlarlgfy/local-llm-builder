# Build a temperature converter

Create a small Python program using only the standard library.

## Required behavior

- converter.py exports celsius_to_fahrenheit, fahrenheit_to_celsius, and kelvin_to_celsius.
- main.py prints the Fahrenheit value for 20 Celsius when run.
- tests/test_converter.py tests freezing, boiling, negative temperatures, and 273.15 Kelvin.
- README.md explains how to run the program and its tests.

## Acceptance criteria

- python3 -m unittest discover -s tests -v discovers at least three tests and passes.
- python3 main.py prints 68 or 68.0.

Keep the work to two sequential tasks. No downloads, dependencies, or networking are needed.
